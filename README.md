# Maxenoz’s AI Extension

this is my **OpenRouter AI extension for PenguinMod, TurboWarp, and other projects based on [Scratch](https://scratch.org)** which have the Custom Extension thing. Connects with your own API key. Works sandboxed :)

Please read this whole **README.md**.

also I just used GitHub Pages so URL downloading on TurboWarp works :)

# About

This extension connects to **[OpenRouter](https://openrouter.ai)**, an **AI API platform**. It uses the API key included in the string section.

This extension is made for **TurboWarp**, **PenguinMod**, and other **Scratch**-based programming websites/apps.
It is tested only for **[TurboWarp](https://turbowarp.org)** and **[PenguinMod](https://penguinmod.com)**. I won’t test it on other platforms.
It can run unsandboxed **both in TurboWarp and PenguinMod.**

# Setup

**Step 1.** Ensure you have an **OpenRouter account** and an **OpenRouter API key.** If you don’t, click *[here](https://openrouter.ai/sign-in?redirect_url=https%3A%2F%2Fopenrouter.ai%2Fworkspaces%2Fdefault%2Fkeys)*.

**Step 2.** Add the extension to your **PenguinMod/TurboWarp project** using the Custom Extension option and choose **URL.**

**Step 2.5.** Set the URL to https://maxenoz.github.io/Maxenoz-s-AI-Extension/js/MXAI.js, *NOT* the raw GitHub URL (https://raw.githubusercontent.com/…)

**Step 3.** Done! Now, paste your key into the blocks’ **key** string section or do it with a variable. and now you can chat with AIs!

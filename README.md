# Maxenoz’s AI Extension

this is my OpenRouter AI extension for PenguinMod, TurboWarp, and other projects based on Scratch which have the Custom Extension thing. Connects with your own API key. Works sandboxed :)

# About

This extension connects to **OpenRouter**, an AI API platform. It uses the API key included in the string section.

This extension is made for **TurboWarp**, **PenguinMod**, and other **Scratch**-based programming websites/apps.
